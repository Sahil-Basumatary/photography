# Sahil Basumatary Photography

Business platform for the public portfolio, private client galleries, and studio operations at `photography.sahilbzy.com`.


## Stack

- PHP 8.5 and Laravel 13
- Blade, Livewire, and a customised Filament console
- PostgreSQL 18 on private Amazon RDS in `eu-west-2`
- Private S3 media, CloudFront, SQS, and SES
